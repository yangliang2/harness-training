## 既定事实

- **反模式**：给 agent 配的工具/脚本输出从不节制——`make test` 全量 4000 行、自建 MCP 返回整表 JSON。
- **原理一句**：输出越长，真信号埋得越深。
- **实测结论（2026-08-20 终版）**：【需替代】①CC 对 exit≠0 保头截断 ~10KB，杀尾部摘要（首见命中：头 9/9 vs 中尾 0/18）；②模型 54/54 自恢复，代价 +43% 轮次/+46% 成本；③PostToolUse 截断 hook 对 exit≠0 完全不生效 + 输入预截断 30KB——原交付物方案死亡；④语义截断（grep±上下文）9/9 且最便宜。
- **调研三档**：
  - 水文区：输出污染概念、安静 flag、让 agent 自己 grep（官方背书）。
  - 值钱区：**靶心候选"防线在失败时缺席"**——安静 flag/截断 hook/harness 截断三道防线在 exit≠0 那次运行上全失效或反作用；保头杀尾（水位最低点）。
  - 威胁项：PostToolUseFailure 已拆分为独立事件（"不生效"已被固化为设计，无迁移说明）；issue #68951 给出 Bash updatedToolOutput 对象形态（{stdout,stderr,interrupted}）。
