# INDEX.md 模板（《改掉这个习惯》第 3 集交付物）

> 放在 repo 根或 docs/ 根。全表一页以内——超了说明第一级还不够"索引"。
> 常驻的只有这页地图；正文原地不动，按需取用。

| 名称 | 什么时候读我 | 适用版本 | 路径 |
|---|---|---|---|
| ANR 排查经验（锁竞争类） | 排查偶发 ANR 且主线程 trace 指向 Blocked 状态时 | v2 异步架构起 | docs/experience/anr-lock.md |
| 支付接口决策记录 | 改动支付链路、疑惑"为什么不用 X 方案"时 | 2025-Q3 架构纪元 | docs/adr/012-payment.md |
| （示例行，替换为你自己的） | 触发条件式的一句话，不写内容摘要 | 版本/纪元锚点 | 相对路径 |

## 接线（两步，全官方机制）

1. CLAUDE.md 里加：
   ```
   @import INDEX.md
   查历史经验先查 INDEX.md，按路径取正文，不要全文检索 docs/。
   ```
2. settings.json 里挡住档案区（best-effort，Grep/Glob 会尽力跳过）：
   ```json
   { "permissions": { "deny": ["Read(docs/archive/**)"] } }
   ```

## 准入规则（防复发）

新文档不进目录 = 不存在。进目录前过三道门：
1. 代码里读得出来吗？读得出 → 不写。
2. 它训练时就会吗？会 → 不写。
3. 什么时候该读你？答得出 → 写进目录一行；答不出 → 躺档案。
