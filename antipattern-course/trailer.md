# 《改掉这个习惯》· AI 使用反模式七讲 —— 预告稿

> 内部注：按标题纪律，预告不点名习惯本身（藏进场景里）；不出现未经开拍复核的数字；每集"带走物"与设计档交付物清单一致。ep3/ep4 定稿方向若变，第 3、4 集段落需同步改。

---

你的 AI 不是不行，是你惯出来的。

用 Claude Code / Codex / Cursor 的这些日子，你大概攒下了一堆"顺手就这么干"的习惯：装的东西从不清理、工具吐什么就接什么、一个会话从头用到尾、它说"搞定了"你就信了。每一集 5 分钟，只干一件事：点名一个你天天在犯的习惯，一句原理讲清它为什么出事，再给一个当天就能做完的改法。

这门课的纪律：能实测的我们先自己测，测不出来的明说是推断，不编数字；每个方法什么时候会失灵，直说。以 Claude Code 演示，思路通用于所有 coding agent。

## 七集分别讲什么

**第 1 集｜让 AI 立刻变聪明**
你装的那些 MCP、插件、规则文件，每一个都在每一轮对话里占着位置——装的时候都有用，但从没删过。官方一直在拼命给系统提示词瘦身，你一不小心又全加回去了。这一集带你跑一次官方体检，把"零次使用"的东西揪出来。
👉 带走：环境体检清单 + 一句判据："它每轮都在场吗？它挣得回这个位置吗？"

**第 2 集｜让 AI 听得清**
接了个工具，一次吐回两百个字段，你只用三个——而每一轮，它都在全价重读这两百个。贵的不是长输出，是"每一轮"。这一集两条路：该抽的抽，该落盘的落盘。
👉 带走：抽取模板 + 落盘模板 + 判据："它每次真正用哪几个字段？答得上来就抽取，答不上来就落盘。"

**第 3 集｜让 AI 不记错事**
repo 里堆着历年的调研、复盘、经验文档——它撞见了，就当真。可那些文字原本是写给"会怀疑的人"看的。这一集讲怎么喂、怎么验，别让旧经验替它做决定。
👉 带走：文档分诊表 + 判据："它给你的方向，是自己验证过的，还是从旧文档里匹配来的？"

**第 4 集｜让 AI 一学就会**
内部工具、自研框架、冷门链路——主流工具它见过百万次，你的自研它一次没见过。但"自研=坑"是懒答案，这一集给自研"计税"：三档选型，什么时候零税，什么时候必须拿文档对冲。
👉 带走：选型判据卡 + 判据："让它裸写一段调用——一次写对零税，查文档写对低税，查完还编错高税。"

**第 5 集｜让 AI 下午不变笨**
开个会话干一天，决策和约定全存在对话里，上下文满了就压缩续命——每压一次，开头的重要约定就薄一层，压到后面它连自己答应过什么都不记得。这一集装仪表、定阈值、写交接单：看着表开车，到线就换班。
👉 带走：HANDOFF 交接模板 + 判据："到线就换班；任务收工就开新会话——别把一整个旧任务的历史拖进新任务。"

**第 6 集｜让 AI 不走神**
主线干着干着，"顺便帮我改下 README"——最后合进去的 diff 里就躺着不相关的东西。同一个会话里的每句话，都在抢它的注意力。这一集四个出口，全是原生命令：问的、做的、要上下文的、无关的，各走各的门。
👉 带走：四出口判据卡 + 判据："和当前任务无关的话，不进这个会话。"

**第 7 集｜让 AI 说到做到（压轴）**
"已完成""已确认""我会改正"——它的输出只是文字。"做完了"和"真的做完"之间，差一个可以检查的工件。这一集用两个拦截钩子把"说说而已"当场拦下（本课程开发中真实抓到过两次，有转录为证）。
👉 带走：双拦截脚本 + 三扳机卡 + 判据："不落盘的承诺，按不存在处理。"

## 学完这七集，你手里多了什么

- **七份当天能落地的配置、清单和脚本**：环境体检清单、抽取与落盘模板、文档分诊表、选型判据卡、HANDOFF 交接模板、四出口判据卡、双拦截脚本。全部配外部判据——改没改到位，自己跑命令验证，不靠感觉。
- **七条带得走的判据**：清单会过时，判据不会。下一代的模型和工具出来，"它每轮都在场吗""它真正用哪几个字段""说和做之间差没差一个工件"这些问题，照样能帮你当场做判断。
- **一种诚实的看 AI 的方式**：不吹"AI 万能"，也不吓你"AI 危险"——只指给你看，哪几个习惯在偷你的注意力、你的钱、和你的信任。

七集，七个习惯，每集五分钟。
模型一直在升级——你的使用习惯，多久没升级了？
