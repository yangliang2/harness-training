## 既定事实

- **反模式**：支线话题全进上下文——正线稀释 + diff 混入不相关改动。
- **原理一句**：同一会话里的每句话都在抢它的注意力。
- **实测结论（2026-08-19）**：【可实拍（开拍即验）】三命令无头不可用，但均为交互命令；版本门槛本机满足。
- **调研三档**：
  - 水文区："新任务新会话"、kitchen sink session（Anthropic 官方亲自命名）。
  - 值钱区：**五命令决策树（/btw /fork /subtask /clear /rewind 五选一）市面无体系内容，是空白**；ICLR 2026 最佳论文背书（多轮对话平均降 39%，arXiv 2505.06120）；"窗口没满就没事"是错觉；compact 不去污染（错误假设被摘要固化）；/fork 语义三迁，存量认知全过时。
  - 威胁项：**Kimi Code 的 /fork、/btw 语义不同且没有 /subtask——引用必须限定 Claude Code**；/btw 引入版本（v2.1.72）来自 issue 转述，上镜精确版本号需再核官方 CHANGELOG。
