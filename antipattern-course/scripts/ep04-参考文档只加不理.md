## 逐字稿

### 0:00–0:20 承接 + 行为点名

【口播】
上一课劝你把知识搬进 repo，用它本来就会的方式给。这一课，管管搬进来的这堆东西。复盘、调研、案例库、wiki——是不是全灌进去了？总觉得资料给得越多，它就越懂你们团队。你是不是也这样？

【画面】
承接卡 1 秒【可生成】→ 实拍：`docs/` 目录树展开，几十份 md 滚屏【实拍，v2 夹具】；配一个知识库界面一闪（泛化到非 repo 场景）【可生成】。

### 0:20–0:45 反转钩子（29 次投毒失败）

【口播】
先说一个我们自己的实验。为了拍这一集，我们花了几十美元、前后二十九次，想让 AI 被 repo 里的过时文档带偏——精心埋了假线索、旧结论、过期经验。结果：二十九比零，一次都没骗成。它比你想的难骗得多。那这一集讲什么？讲账单。它没被骗，但每一次，它都把你堆的纸**全价读了一遍**。

【画面】
实验记录卡【可生成，数字逐字来自 spike 记录】：四轮布景迭代 29/29 未中毒，字幕标注各轮 N 与日期。切账单数字特写【实拍存档或卡】。

### 0:45–1:05 原理立柱

【口播】
为什么堆料没用？因为**它不会学**。你给它的文档，不进它的记忆，只进它的桌面——**每个会话，它都是第一天上班**。人教一遍就会，它每次都从头翻你桌上那堆纸：纸越多，翻得越久、越贵；相似的纸越多，越容易拿错。

【画面】
原理卡【可生成】："文档不进记忆，只进桌面"→"每个会话都是第一天上班"两行递进弹出。

### 1:05–1:35 税实测（A/B 主镜头）

【口播】
账单长这样。同一个排查任务：左边，repo 里堆着五十份历史案例；右边，同样的文档，但常驻的只有一页目录。轮次差 __%，成本差 __%——**答案质量一样**。差的不是它的能力，是你让它翻多少纸。

【画面】
分屏实拍【实拍，v2 夹具】：堆料组 vs 目录组同任务。收尾数字卡【可生成，v2 占位待填，字幕标注 N】。文献角标【可生成】：常驻文档 +20–23% 成本（4 组 agent 实验，预印本）；agent 的 token 大头本来就是"读"（76.1%）。
【B 措辞（v2 不过时）】数字卡改引文献：按需索引显著降低 token 成本（双 agent 消融、正确率零差异），本段口播改"文献实测"口径，不出自家百分比。

### 1:35–2:05 机制段（人视角 + 相似不命中）

【口播】
更麻烦的是，这些文档还全是**写给人看的**。人读文档自带一套本事：看日期、认作者、知道哪个模块早重写了。它一样都没有——你堆给它的，是一摞抹掉了时间轴的纸。**这些文档都没错，错的是读者换了。**而且研究发现一个反直觉的事：真正伤它的不是无关的纸——是**相似但不命中**的纸。你精心收集的"相关案例"，恰恰是杀伤力最大的品种。

【画面】
机制卡【可生成】：左列"人自带：日期/作者/组织记忆"，右列"它：无"。反直觉卡【可生成，标注出处与模型代际】：相似不命中文档 +1 篇 → 准确率 −25%；完全无关的随机文档 → 无害甚至 +35%（SIGIR 2024，7B 模型实验，量级勿外推）。

### 2:05–2:25 条件化危害（诚实卡）

【口播】
要说清楚：它多数时候能自救——只要代码能查、测试能跑，它就会去验证，我们二十九次没骗成就是证据。但当**验证没处可查**的时候——问题不可复现、没有测量手段——它就只剩你那堆纸了。那种时候，公开实验里最强的模型也会被过时文档带偏到底。

【画面】
条件卡【可生成】："危险区 = 测量不可得 × 相似案例密度高"；角标：唯一信息载体条件下被误导率 68–100%（开源可复现实验，未同行评审）。

### 2:25–3:45 解法（三道门 + doc-index-builder）

【口播】
解法不是删文档，也不是重写——是**换一种给法**。判断标准三道门：第一道，代码里读得出来的，不写——它自己会看代码，抄代码的文档只会过时打架。第二道，它训练时就会的，不写——框架教程、通用最佳实践，你付不起给它复读教材的房租。第三道，剩下的真金——决策为什么这么定、踩过什么坑、哪条经验适用到哪个版本——每一份回答一个问题：**什么时候该读你？**答得出，就在目录里占一行。描述区有个 skill 帮你干这件事：它扫一遍文档，每份给出三道门判定和证据，你只需要批那张表。批完生成一页目录，挂进常驻——**常驻的只有地图，正文按需取**。网站都开始给 AI 准备 llms.txt 了，你的 repo 也该有这一页。

【画面】
三道门漏斗卡【可生成】先立框架 → 实拍四连【实拍，v2 夹具】：①跑 doc-index-builder → ②分诊表特写停 3 秒（一份"复述代码"被拒带 文件:行号 证据、一份框架教程被标"训练已会"、一份事故复盘拿到"何时读我"行 + 适用版本）→ ③人批表 → ④INDEX.md 生成 + CLAUDE.md 接线两行特写。llms.txt 官网真截一闪【真截】。

### 3:45–4:15 诚实边界

【口播】
三句丑话。第一，这一集劝退的是"堆"，不是文档——**策划过的、准确的、版本对得上的文档，收益是巨大的**，公开实验里能把通过率拉满。第二，"先查目录"那行规则是建议不是铁闸——它想绕过去自由搜索还是能搜到，真正的硬隔离只有档案区那一道。第三，skill 判"它训练时会不会"是模型自评，会看走眼——批表那一步是给你设的，别跳过。

【画面】
三句边界卡【可生成】逐条弹出；第一句配 Vercel 数字角标【可生成，标注厂商自评博客、条件合取】。

### 4:15–4:40 收尾判据

【口播】
判据带走，往后每份新文档入库前过三道门：**代码里读得出来吗？它训练时就会吗？什么时候该读你？**前两道拦住的，永远别写；第三道答不出的，躺档案。新文档不进目录，就等于不存在。

【画面】
三道门判据卡【可生成，card2png】停 3 秒供截图。

### 4:40–5:00 交付物 + Cursor + 下集钩子

【口播】
描述区三件：扫文档的 skill、目录模板、判据卡。Cursor 用户照用——skill 目录它官方兼容，目录放 AGENTS.md，档案区用 .cursorignore 挡，对应栏写全了。文档的账清了——可你那个从早上开到现在的会话，本身就是一堆没理的纸。下一集：别让它下午变笨。下集见。

【画面】
三件套一屏【可生成】→ Cursor 对应栏特写【可生成】→ 下集预告卡【可生成】："让 AI 下午不变笨"。
