【画面】

### 1:50–3:10 解法一（治）：跑一次 /doctor

【口播】
药很简单，一条命令：`/doctor`。它把你装过的所有东西——MCP、skill、plugin、CLAUDE.md——拉成一张体检表。重点看这一列：Uses，使用次数。零次的，就是你囤的。判据一句话：**上周零次使用，就删。**它会给清理提案，带确认环节，不会偷偷动手。删完别急着走，跑一次 `/context` 复核——省了多少，自己看见才算数。

【画面】
【实拍】跑 `/doctor` → 等待段"已剪辑"字幕 → 体检表全景停 3 秒（四类组件各至少一行，Uses 列红框）→ 指向"零次使用"行 → 确认清理 →【实拍】`/context` 复核前后对比。**拍摄纪律：配置面实录、建议内容走策展**——报告文字为模型生成，预跑 2–3 次选建议合理的一条存档，字幕如实标注。版本角标【可生成】：/doctor 配置体检为 v2.1.206+ 行为。

### 3:10–3:55 解法二（防）：归位

【口播】
删是治病，还有防病：装的时候就问一句——**这东西，别的项目用吗？**不用的话，装项目级，别装全局。这不是我的洁癖，是官方的默认：`claude mcp add`，不加参数，默认就是只装当前项目——装全局，是你自己主动选的。回头看你的体检表，Scope 列如果全是 user，病根就在这。

文件名：`env-checkup-checklist.md`（描述区/仓库下发）

```markdown
# 环境体检清单（《改掉这个习惯》第 1 集交付物）

## 体检（治）：约 10 分钟

1. 跑 `/doctor`（需 Claude Code v2.1.206+），等体检表。
2. 看 Uses 列，圈出"零次使用"的 MCP server / skill / plugin。
3. 判据：**上周零次使用，就删。**按它的清理提案逐项确认。
4. 删完跑 `/context` 复核——/doctor 的数字是磁盘估算（est.），实际省多少以 /context 为准。

注意：
- /doctor 的 keep/remove 是建议不是圣旨；使用计数的统计窗口可能很短，拿不准的先留。
- `claude mcp remove` 会永久删除该 server 配置并清掉 OAuth 凭据——删带登录的 server 前想清楚，重装需重新授权。

## 归位（防）：装新东西时问一句

> 这东西，别的项目用吗？

- 不用 → 装项目级。`claude mcp add` 默认就是项目级（local）；skill 放 `<repo>/.claude/skills/<name>/`。
- 用 → 才装全局（`--scope user` / `~/.claude/skills/`）。
- 体检表 Scope 列全是 user = 病根所在。

归位操作的两个坑：
1. skill 同名时 **personal 压 project**——把全局 skill 挪进项目后，必须删掉 `~/.claude/skills/` 下的同名目录，否则项目级那份永远不生效。
2. MCP 没有 move 命令：迁移 = 记下配置 → `claude mcp remove` → `--scope project` 重新 add（或手写 `.mcp.json`）；带 OAuth 的 server 迁移后需重新登录。

## 可迁移判据（清单会过时，这两句不会）

> 它每轮都在场吗？它挣得回这个位置吗？
```
