## 既定事实

- **反模式**：自研框架/非标 MCP/冷门链路，逼 agent 在训练分布外裸泳。
- **原理一句**：它的"会"来自训练时见过——主流工具见过百万次，自研一次没见过。
- **实测结论（2026-08-20 终版）**：【需替代】help 合格的自研工具单工具 10/10、三工具串联 7/8 零工具错误，轮次成本反超 gh 组（11.6 轮/$0.368 vs 13.2 轮/$0.459）——**方向反转：主流工具有接口税（base64/jq 摩擦）；自研税只在五条件显性化**（文档缺失或误导/无 schema MCP/轮次预算紧/工具数量爆炸/隐式状态）。肌肉记忆的真实溢价 = 零方差不是正确率。
- **调研三档**：
  - 水文区："模型对主流工具更熟"、"能用 gh 别自建 MCP"（CLI 派已是多数派）。
  - 值钱区：命名空间空白（"自研工具=加税"无约定俗成名，可占）；五条件；反转（help 合格零税）；兼容外壳方法论（glab 官方 README 写明照 gh 做；OpenAI-compatible API 是更大先例）；"描述越全越好"也错（+5.85pp 成功率但 +67% 步数）。
  - 威胁项：MCP 规范正文至今不给描述写法指导（事实标准在 Anthropic 工程博客）；glab v1.114 已有 `glab mcp` 子命令（CLI/MCP 融合，讲课留活口）。

## 讨论记录

- 2026-08-22：**首轮讨论：重构派方案（未采纳）**。基于两轮证伪 + 方向反转（自研组反超 gh 组），提出反模式改写 D 方案"工具交付不验收"（兼容全部实测事实：help 合格零税是侥幸、help 说谎翻车在所难免；解法 = 三档选型 + 裸写判税卡）。用户裁决见下条。
- 2026-08-22：**用户裁决：方向保留，定性为构造问题（同 ep03 先例）**——"有非常多糟糕的 MCP"。构造缺口具体化三条：①两轮 spike 的"自研工具"实为合格 --help 的 CLI shim，CLI 有自助文档通道，烂 MCP（无 description/无参数说明）模型无处可读——**反模式的真实目标从未被测过**，10/10 证伪的是"文档合格的 CLI"不是"烂 MCP"；②help 是我们自己写的"合格线以上"，不代表真实中位数（arXiv:2602.14878：97.1% 有 smell、56% 没说清用途）；③工具仅 3 个且命名语义清晰，未触"数量爆炸/职责重叠"条件。新 spike 原则：烂度对齐全真实中位数（smell 分类学），不造 caricature；任务与数据复用 ep04-multi-mcp 夹具，同任务换烂 MCP，直接对照既有基线（B 组 7/8、零工具错误）。
- 2026-08-22：**ep04-bad-mcp spike 布景定稿（待跑）**。三个构造升级：①真 MCP 协议（stdio server 挂 `--mcp-config`）——description 是唯一文档通道，补上"无处可读"机制差异；②烂度对标 [arXiv:2602.14878](https://arxiv.org/abs/2602.14878) 六 smell 分类学的真实中位数（六成分：Purpose/Guidelines/Limitations/Parameter Explanation/Length & Completeness/Examples；六 smell：Unclear Purpose 56%、Missing Usage Guidelines、Unstated Limitations、Opaque Parameters、Underspecified、Exemplar Issues；多数工具同时中多条），M1 配置 = 用途不清 + 参数无 intent 说明 + 无使用指引，每条 smell 有流行度出处可挡"故意写烂"反驳；③**错误信息也是文档通道**——前两轮 CLI shim 报错是规范 GNU 风格（暗中递答案），真实烂 MCP 报错同样烂（`internal error` 一句），M1 报错按中位数烂配。分组：M1 中位数烂度 / M2 误导档（description 说谎：参数含义标反、默认值描述与实际不符）/ M3 数量爆炸档（25 个相似工具埋 3 个真目标，可选二轮）。任务与数据原样复用 ep04-multi-mcp，基线已有（好文档 CLI 组 7/8、零工具错误、$0.368）。**生死判据预登记**：M1 翻车 → 原主张成立，demo 拍 M1（"这就是 56% 真实 MCP 的样子"）；M1 不翻 M2 翻 → 主张收窄为"缺失可自救、误导才致命"，demo 拍 M2；M1、M2 都不翻 → 逆分布在 MCP 层证伪，回重构方案（D 或反转叙事）。预算 2 组 × N=8 × ~$0.4 ≈ $8。候选原理一句（若得剂量-反应曲线）："缺失让税显性化，误导让税致命。"
