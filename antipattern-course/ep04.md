## 既定事实

- **反模式**：自研框架/非标 MCP/冷门链路，逼 agent 在训练分布外裸泳。
- **原理一句**：它的"会"来自训练时见过——主流工具见过百万次，自研一次没见过。
- **实测结论（2026-08-20 终版）**：【需替代】help 合格的自研工具单工具 10/10、三工具串联 7/8 零工具错误，轮次成本反超 gh 组（11.6 轮/$0.368 vs 13.2 轮/$0.459）——**方向反转：主流工具有接口税（base64/jq 摩擦）；自研税只在五条件显性化**（文档缺失或误导/无 schema MCP/轮次预算紧/工具数量爆炸/隐式状态）。肌肉记忆的真实溢价 = 零方差不是正确率。
- **调研三档**：
  - 水文区："模型对主流工具更熟"、"能用 gh 别自建 MCP"（CLI 派已是多数派）。
  - 值钱区：命名空间空白（"自研工具=加税"无约定俗成名，可占）；五条件；反转（help 合格零税）；兼容外壳方法论（glab 官方 README 写明照 gh 做；OpenAI-compatible API 是更大先例）；"描述越全越好"也错（+5.85pp 成功率但 +67% 步数）。
  - 威胁项：MCP 规范正文至今不给描述写法指导（事实标准在 Anthropic 工程博客）；glab v1.114 已有 `glab mcp` 子命令（CLI/MCP 融合，讲课留活口）。
